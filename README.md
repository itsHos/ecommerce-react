🎧 Headphone Store - React Project

This is a simple React e-commerce project for selling headphones.
The application displays different headphone products with their images, descriptions, and prices.

The main goal of this project is to practice React fundamentals such as components, props, and reusable UI.

---

🚀 Features

- Display a list of headphones
- Show product image, name, description, and price
- Add products to cart
- Clean and simple user interface
- Built with reusable React components
- Responsive design

---

🧠 What I Learned

While building this project, I practiced:

- React Components
- JSX
- Props
- Rendering lists of products
- Event handling in React
- Creating reusable UI components

---

🛠️ Technologies Used

- React
- JavaScript
- HTML
- CSS

---

🎯 Project Purpose

The purpose of this project is to improve my React development skills and understand how to build a simple e-commerce interface using component-based architecture.
